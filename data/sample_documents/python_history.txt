Python is a high-level, general-purpose programming language known for readable syntax and broad use in software development. Python traces its origins to work by Guido van Rossum at the Centrum Wiskunde & Informatica (CWI) in the Netherlands. The language was influenced by ABC and was designed as a successor to the ABC programming language.

Guido van Rossum began working on Python in the late 1980s. The first public release of Python, version 0.9.0, appeared in February 1991. Python later developed through the Python 1.x, 2.x, and 3.x series.

Python was designed with an emphasis on simplicity, readability, and programmer productivity. Its standard library and ecosystem have contributed to its use in education, automation, scientific computing, web development, data analysis, and artificial intelligence.
